Four things to check first
  1. Which Retroid? Open Settings → Storage. About 128 GB total means a 3+; about 32 GB means the original RP3. The 3+ is much stronger, and this decides how much Wii you can play.
  2. Which phone? Settings → About phone → Model number. S921 is an S24, S926 an S24+, S928 an S24 Ultra. A number ending in U (US) has the Snapdragon chip, which is the better one for emulators. (There's no "S24 Pro".)
  3. Miyoo firmware: Settings → Device Info → Version. It needs 20230505 or newer for Onion.
  4. Your computer: Windows or Mac. It changes how you format the SD card.

Send me those four answers and I'll tailor any step that depends on them.

Device 1

Miyoo Mini Plus: Onion OS

Onion v4.3.1-1 is the newest stable release (June 2024). I downloaded it and checked that the zip holds the folders it should.

Make it run smoother

  • Mild overclock for heavy PS1 games. Create a text file RetroArch/cpuclock.txt containing only 1800. Onion's docs say this gives "up to 20%" more speed; 1800 is their recommended stable value for the Mini Plus. Don't go higher.
  • PS1: keep rewind and fast-forward off. Onion says "performance may suffer greatly" otherwise.
  • GBA running slow? Press Y on that game and switch its core to gpSP. It's faster, but it needs a gba_bios.bin dumped from your own GBA.
  • Save settings the Onion way. Make changes in RetroArch's Quick Menu → Overrides → Content override. Resetting from inside RetroArch "will break Onion functionality".
  • Save battery: brightness under about 70%, Wi-Fi off when you're not using it, and headphones ("the speaker is the most battery-hungry component").
  • Shut down correctly: hold POWER (it saves first). A long hold to force it off is only for a frozen device.
Watch out for the update app

If you install Onion's OTA Update app, its default channel is beta (a 4.4 beta from January 2026 with an open RetroAchievements bug). Switch it to stable before running it, or skip it; you're already on the newest stable version.

Free extras

  • Ports Collection: 24 complete games are free to play. The other 37 need data files from games you own.
  • Themes: preview and apply them in the Themes app.
  • Pokémon-style clock games: Tweaks → System → Date and time → "Set automatically via the internet".
  • Back up your saves by copying the Saves folder to your computer now and then. That folder holds everything.
Device 2

Retroid Pocket 3 / 3+

The 3+ has a Unisoc T618 chip, 4 GB RAM, Android 11 and no fan. The original RP3 has a weaker T310 with 2–3 GB. Check storage first (see the top of this page).

About "recoding" the Retroid

The chip's speed is fixed in hardware, and no software can rewrite it. I also looked for custom firmware that speeds up the 3+. Nothing reliable exists: LineageOS covers only newer Retroids (Pocket 6 and Nova), and GammaOS never released a Retroid build and was archived in May 2026. Flashing unofficial system software can also brick the device.

Most of the real speed comes from the right emulator build plus per-game settings. The rest comes from these system tweaks:

The big one

Wii on the Retroid 3+

The community RP3+ test sheet rates about two-thirds of its 71 tested Wii games as Perfect or Great. Testers picked which games to try, though, and most used older speed-focused Dolphin builds that are no longer officially available. Expect the light and 2D games to be smooth and the big 3D games to be choppy.

Which Dolphin to use

  • Keep the preinstalled "Dolphin for Handheld" from Retroid's setup wizard. The community sheet calls it the best performer on GameCube.
  • Also install official Dolphin (Google Play; current release 2609a, October 2026). It's actively developed, so try each game in both and keep whichever runs better.
  • Don't uninstall the preinstalled one with "keep data". On a Retroid Pocket 5 that blocked reinstalling Dolphin until the owner re-ran the setup wizard. If you remove it, remove its data too.
  • Skip random "fast" Dolphin forks. The famous MMJR builds are gone, and the one surviving fork tells beginners to use official Dolphin.

Controls without a Wii Remote

  • Pointer on the right stick: Controller settings → Wii Remote → Motion Simulation → map Point to the right stick and tick Relative Input.
  • Or point with the touchscreen: Dolphin's Touch IR Pointer (Follow or Drag mode). Use one pointer method per game; mixing them confuses it.
  • Shake: map Wii Remote "Shake" to R2 (and Nunchuk shake to a spare button).
  • Sideways games (like New Super Mario Bros. Wii): make a second controller profile with "Sideways Wii Remote" ticked.

Device 3

Galaxy S24-series phone

The strongest of the three by far. Use it for the Wii and PS2 games the Retroid can't handle, plus 3DS, Vita and Switch.

Two phone gotchas

No microSD slot on the S24, so PS2, Wii and Switch games will fill a 128 GB phone fast. Switch emulators were all hit by Nintendo legal notices in February 2026 and moved off GitHub. Eden is the maintained one, and you should download it only from eden-emu.dev; copycat sites have pushed malware. It also needs keys and firmware dumped from your own homebrew-capable Switch.

Official sources only

App hub

Every link goes to the project itself. Avoid "all-in-one emulator packs" and repack sites; they're where malware comes from.

Start with Obtainium

Obtainium (free, open source) installs Android apps straight from their GitHub release pages and alerts you to updates. Install it on the Retroid and the phone, tap Add App, and paste a GitHub link from the table below. This directory has one-tap configs for hundreds of apps. Keep each app on one install source: an app installed from the Play Store won't take updates from Obtainium until you uninstall it (back up saves first).

One menu for all your games (a frontend)

  • Retroid: start with its built-in launcher, which Retro Game Corps calls "one of the best built-in launchers" on any handheld.
  • ES-DE (3.5.0, paid, one purchase on Patreon covers all your devices): the most powerful, with box art and themes. Its FAQ warns that on devices with about 4 GB of RAM, like the 3+, Android may close it while a heavy emulator runs.
  • Daijishō (free, Play): good, but its developer is on a break.
  • Beacon ($2.99, Play): actively updated and easy to set up.
  • On Retroid, pick the AOSP launcher in the setup wizard if you switch to ES-DE or Daijishō.
Tie it together

Saves, achievements & box art

  • Carry a game between devices by using the same RetroArch core for that system on every device, and moving the in-game save (the .srm file), not the save state. Save states often break between versions. Make an in-game save before you switch, and test with one game first.
  • Syncing automatically: the official Syncthing Android app was discontinued in 2024. The fork that replaced it changed owners in late 2025 without a clear handover. It's on F-Droid, and reviewers found nothing malicious, but for now copying save folders by USB is the safer choice. On the Miyoo, everything lives in Saves/.
  • Achievements: a free RetroAchievements account works in RetroArch on all three devices (Settings → Achievements) and in Dolphin. For Wii achievements, Dolphin requires "Dual Core" to be off, which costs speed on the Retroid.
  • Box art: use the free ScreenScraper account in each frontend's scraper. For a big library, Skraper on a Windows PC is faster. For the Miyoo, follow Onion's Skraper settings, which use an Imgs folder with a capital I.
The part I can't do for you

Getting games

I won't download or link game ROMs, ISOs or BIOS files. Commercial games are copyrighted, and there's no legal all-in-one ROM pack on GitHub; repos that claim to be one are piracy and get taken down. These are the routes that are actually legal:

Copy carts you own
  • GB Operator ($49.99): Game Boy, GBC and GBA carts plus their saves
  • SN Operator ($59.99): SNES
  • Open Source Cartridge Reader: DIY build, NES/SNES/N64/Genesis and more
Copy discs you own
  • Wii & GameCube: mod your own Wii with wii.hacks.guide, then dump discs with CleanRip
  • PS1 / PS2: a PC disc drive plus redumper or MPF
  • PS2 BIOS: PCSX2's guide (biosdrain). It also works for DuckStation.
Free & legal
  • Homebrew Hub: 1,600+ free GB/GBC/GBA/NES games
  • itch.io homebrew (check each game's terms)
  • The 24 free games in Onion's Ports Collection

Already have games on the old Miyoo card? Copy its Roms folder to your computer before anything else, then drop each game into the matching folder on the new card.
